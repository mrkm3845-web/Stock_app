1. 30秒でわかる全体像

データの更新と採点は、全部コンピュータがやります。あなたがやるのは3つだけです。

作戦を決める
夜か週末に作戦ノートを作る（/strategy-note）。ここで「買う・待つ・見送る・損切り」を決める。
注文を置く
証券会社にOCO（利確と損切のセット注文）を置く。これが本体。Botは代わりに約定しません。
見て、記録する
日中は今日の作戦とDiscord通知を見る。売買したら台帳を更新する。
自動で回っているもの: 平日5回のスクリーニング → 夜にAI分析 → 日中7回のトリガー監視 → 土曜に週次答え合わせ → 月1回バックテスト。人が押さなくても進みます。

どのページを、いつ見るか

いつページ何のため
毎朝今日の作戦OCOが生きているか、今日やること
日中今日の作戦（通知が来たら）損切接近・買い到達の確認
売買した日取引記録 → ノート更新約定を記録し、台帳を更新する
夜・週末作戦ノートなぜその水準かを決める（＝台帳をつくる）
土曜振り返り先週の答え合わせ
月1回その他 → AIの学び検証の傾向を確認
迷ったときその他 → 見方ガイド / 運用マニュアル読み方・手順
どのページも右上の並びは同じです（スクリーナー / 今日の作戦 / 取引記録 / 振り返り / 作戦ノート / その他）。

時刻は日本時間。平日の例です。自動は何もしなくてOK、手動だけ動きます。

自動で書き換わるファイル

docs/history/（価格・スコア）／docs/recommendations.json（AI推奨）／docs/picks/（日次スナップショット）／ docs/weekly/（答え合わせ）／docs/strategy/status.json・events.json（作戦の現在状態と履歴）／ docs/strategy_params.json（月次の検証結果）
→ これらは手で編集しない。次回の自動実行で上書きされます。
失敗したときは？赤いバツが出て、その回のデータ更新は止まります。次の回（数時間後）に自動で再挑戦されます。 通知が来ないだけで、あなたが何かする必要はありません。ただし2日続けて更新されないときは Actions の画面を確認してください。

4. 自分が手動でやること

4-1. 毎営業日の朝（5分）

  1. 今日の作戦を開く → 「今日やること」を上から確認
  2. 証券会社でOCO（利確＋損切）が生きているか確認。前日に約定・取消していないか
  3. 買い注文を置くのは、入口の価格と条件の両方が満たされたときだけ
条件NGなら買わない。「価格が来た」だけでは買いではありません（地合い・セクター・決算5日前を確認）。

4-2. 売買した日（必須・10分）

ポジションが変わったら、作戦台帳を更新します。これを忘れると、翌日から古い保有で判定されます。

  1. 取引履歴CSVを最新にする（証券会社からダウンロード）
  2. opencode で /strategy-note を実行
  3. 生成された作戦台帳（保有・OCO水準）を確認して、必要なら手で直す
取引履歴CSV（tradehistory(JP)_*.csv）は絶対にコミットしない。読むだけです。

4-3. 夜・週末の作戦づくり（15〜30分）

  1. opencode で /strategy-note（追加の希望があれば後ろに書く）
  2. 最初に「作り直す必要があるか」の判定が走ります（下の表）
  3. 古ければデータの鮮度チェックと更新が自動で走ります（数分かかります）
  4. 作戦ノート（なぜそう決めたか＝記録）と作戦台帳（今日の水準＝実行）が更新される
  5. コミット・push まで自動で行われ、数分後に公開ページへ反映＋Discordに通知
判定どうなる
更新不要その日の確定終値で最新で、売買の変化もなし → 何も上書きしません（ノートも台帳も作りません）
価格が古いデータを更新してから作り直します。それでも古ければ停止します
売買が新しい同じ終値でも、約定に合わせて台帳を作り直します
当日の途中データ作りません。「引け後（15:30以降）に作り直してください」と止まります
作戦は「確定した終値」で作ります。15:30より前は前営業日の終値を使います（当日の途中の値では作りません）。 昼休みや前場に作ると、前日終値ベースになるか、当日の途中データが入っていれば止まります。
中で起きていること: tools/refresh_data_if_stale.py --refresh →（古ければ）main8.py → tools/prepare_strategy_note.py → ノートと台帳を生成 → docs/weekend/ と docs/strategy/active.json を更新
AIキーが無いローカルでは、テクニカルのみ更新されます。AIが古いままなら、ノートにその旨が明記されます。スコアと台帳を優先してください。

4-4. 「今すぐデータを更新したい」（2〜5分・待つだけ）

スマホからでもできます。

  1. 今日の作戦の「データ更新（AI）」ボタン → GitHub の Run workflow を押す
  2. そのまま3〜5分待つ（スクリーナー＋AI＋引け後チェックが走ります）
ページのボタン: 今日の作戦 → 「データ更新（AI）」／「手動チェック」（トリガー判定だけ）

4-5. PCから手で動かすコマンド

チャットで頼めば実行できますが、自分で打つときはこれだけ覚えれば足ります。

やりたいことコマンド
データが最新か確認 uv run --no-project --python 3.11 --with pandas_market_calendars python tools/refresh_data_if_stale.py --check
作戦を作り直す必要があるか判定 python tools/plan_staleness.py
古ければ更新（AIも） uv run --no-project --python 3.11 --with pandas_market_calendars python tools/refresh_data_if_stale.py --refresh
作戦の判定を今すぐ実行 uv run --no-project --python 3.11 --with pandas --with numpy --with yfinance python tools/check_strategy_plan.py --mode eod --force
作戦用の材料を集める python tools/prepare_strategy_note.py
--check は確認だけ、--refresh は更新まで。--force は市場時間外でも判定します（確認用）。 ローカルで更新してもコミットされません。公開ページに反映したいときは GitHub Actions の「データ更新（AI）」を使ってください。

4-6. 月に1回（10分）

  1. 週次答え合わせで、先週の推奨が当たったか外れたかを見る
  2. 月次バックテストの結果で、パラメータが勝手に変わる（条件を満たしたときだけ）
  3. 1週間の結果でやり方を変えない。4〜8週間ためてから判断する

6. 通知の種類と意味

Discord に届く通知は4種類です。

通知いつ来る内容
AI推奨 平日 20:17 のAI分析後 その日の推奨銘柄（新規・更新があったとき）
作戦トリガー 日中の監視／引け後チェック 損切・利確・買い入口に触れたとき、条件が崩れたとき（状態が変わったときだけ）
作戦更新 作戦台帳（active.json）が更新されたとき plan_id・基準日・保有/監視/見送りの件数・今日やること。更新のたびに1通（「更新不要」では送りません）
週次振り返り 土曜 09:00 の答え合わせ後 約定件数・勝率・平均リターン・TOPIX超過・ベスト/ワースト・来週の要点

状態の言葉

表示意味あなたの動き
保有OCOの範囲内。何もしないそのまま
損切接近損切りまであと1%以内OCOを確認（動かさない・広げない）
損切到達当日の安値が損切り以下約定を確認。ナンピンしない
利確接近／到達利確まであと1%以内／到達約定確認。トレールするか判断
買い到達入口の価格に触れた（条件もOK）サイズと現金比率を確認して発注
条件NG価格は来たが、地合い・セクター・決算で買えない買わない
期限切れ押し目待ちの期限を過ぎた注文を取り消す
保有期限最大保有日に到達引けで手仕舞いを検討

7. 知っておくこと（制約・落とし穴）

1. 自動実行は遅れる。このリポジトリの実測で、予定より中央値+100分、最悪+3時間43分。 さらに予定の約4割は発火しません（捨てられる）。「9:05に動く」とは思わないでください。
2. 日中の監視は「リアルタイム」ではない。遅れて起動してもその日の高値・安値で判定するので、1時間前に割っていたことは検知できます。 ただし通知は遅く、寄り付き直後の1時間は抜けやすいです。約定の速さは期待しないこと。
3. 通知が来ない＝安全ではない。データが取れない日（休場・遅延・取得失敗）は静かにスキップします。 「静かだから大丈夫」ではなく、OCOが最後の砦です。
4. 損切りは証券会社のOCOで置く。監視Botは通知と記録だけ。発注も注文変更もしません。 相場が急に動いたとき、Botは間に合いません。
5. 価格は「確定終値」で扱う。スクリーナー・スコア・作戦は、15:30より前なら前営業日の終値を使います。 日中に「データ更新（AI）」を押しても、当日の途中の値は入りません（現在値は「今日の作戦」が見ます）。 スクリーナーと取引記録が日中に動かないのは、このためです。
6. 何が正か。迷ったら作戦台帳 → スコア → AIの順。AIは提案、実行は台帳です。
7. 公開ページです。保有数量・損益額・口座情報・個人情報は載せない。保有は銘柄コードとOCO水準まで。 取引履歴CSVは読むだけでコミットしない。
8. 投資助言ではありません。「儲かる」とは言えません。最終判断はご自身で。データは作成時点のものです。

9. 困ったとき（Q&A）

データが古い気がする

今日の作戦のヘッダに「データ: 日付」が出ます。ここが今日（平日の夜なら当日、週末なら金曜）より前なら、 「データ更新（AI）」を実行してください。それでも進まないときは Actions の画面でエラーを見ます。

作戦が空っぽ／「作戦台帳がありません」と出る

台帳（active.json）がまだ無いか、読み込みに失敗しています。opencode で /strategy-note を実行して作り直してください。

Discord通知が来ない

仕様どおりのことが多いです。通知は状態が変わったときだけ。同じ状態が続けば来ません。 加えて、遅延・発火漏れ・データ取得失敗でも来ません。通知の有無で安全を判断しないでください。

AI分析だけ失敗する（赤いバツ）

AIのAPI混雑・上限・キー切れが原因です。スコアとテクニカルは更新されているので、スコアと台帳で判断してください。 AIは「参考情報」です。

銘柄を買った／売った

その日のうちに /strategy-note を実行して台帳を更新します。 古い保有が残ると、翌日から存在しないポジションの損切り接近が通知されます。

損切りに引っかかった

約定を確認し、台帳から外します（/strategy-note で更新）。 ナンピンしない・損切りを広げない。同じ銘柄にすぐ再エントリーしない。

自動実行を止めたい

GitHub の Actions 画面で該当ワークフローを Disable します。ただし止めるとデータが更新されなくなり、 判断の材料が古くなります。止める前に理由を決めてください。

10. 用語集

OCO利確と損切を同時に置く注文。片方が約定したらもう片方は自動で消える。
作戦台帳「いつ・何を・いくらで・どこで損切るか」を書いた表（active.json）。AIより優先。
トリガー発動条件。価格トリガー（例: 1,975まで下がった）と条件トリガー（例: 銀行セクターが強い）がある。
押し目上昇トレンド中に一時的に下がったところ。そこで買うのが「押し目買い」。
ブレイクレジスタンス（上値の壁）を超えて上がること。超えたところで買う。
地合い市場全体が買いに向いているか。「買いやすい（リスクオン）」「慎重に（リスクオフ）」。1306.T（TOPIX連動ETF）が200日線の上か下かで判定。リスクオンは「危険」ではない（リスクを取る＝積極的に買う、の意味）。広がり（25日線・200日線の上比率）は全銘柄で計算し、10銘柄未満は参考外。
スコアトレンド＋流動性を0〜100点にしたもの（v3）。銘柄選びの土台。
AI推奨スコア上位40をAIが順位付けしたもの。提案であって指示ではない。
週次答え合わせ先週の推奨が当たったかを採点し、AIの傾向を補正する仕組み。
ウォークフォワード過去データで「未来を予測できていたか」を検証する方法。月1回・自動。
最大保有日その銘柄を持ってよい期限。過ぎたら引けで手仕舞いを検討。
このページは公開されます。保有数量・損益額・口座情報は載せていません。銘柄コード・価格水準・手順だけです。 投資助言ではありません。最終判断はご自身でお願いします。
